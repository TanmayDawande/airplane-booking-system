Revenue by airline

Flights flown, confirmed bookings, gross revenue and average ticket fare for each carrier.

JOIN, GROUP BY, aggregates
View SQL 
SELECT
    al.airline_code,
    al.airline_name,
    COUNT(DISTINCT f.flight_id) AS scheduled_flights,
    COUNT(CASE WHEN b.status = 'CONFIRMED' THEN b.booking_id END) AS confirmed_bookings,
    COALESCE(SUM(CASE WHEN b.status = 'CONFIRMED' THEN b.total_amount ELSE 0 END), 0) AS total_revenue,
    COALESCE(ROUND(AVG(CASE WHEN b.status = 'CONFIRMED' THEN b.total_amount ELSE NULL END), 2), 0) AS average_ticket_fare
FROM airlines al
LEFT JOIN flights f ON al.airline_id = f.airline_id
LEFT JOIN bookings b ON f.flight_id = b.flight_id
GROUP BY al.airline_id, al.airline_code, al.airline_name
ORDER BY total_revenue DESC;

Airline revenue above ₹5,000

The same grouped revenue query, filtered after grouping with HAVING.

GROUP BY + HAVING
View SQL 
SELECT
    al.airline_name,
    COUNT(b.booking_id) AS total_bookings,
    SUM(b.total_amount) AS gross_revenue,
    ROUND(AVG(b.total_amount), 2) AS average_fare
FROM airlines al
JOIN flights f ON al.airline_id = f.airline_id
JOIN bookings b ON f.flight_id = b.flight_id
WHERE b.status = 'CONFIRMED'
GROUP BY al.airline_id, al.airline_name
HAVING gross_revenue > 5000
ORDER BY gross_revenue DESC;

Seat occupancy by flight

Booked and open seats against aircraft capacity, with the share of the cabin filled.

Five-table JOIN, calculated column
View SQL 
SELECT
    f.flight_number, al.airline_name, orig.city AS origin_city, dest.city AS dest_city,
    ac.model AS aircraft_model, ac.total_seats,
    COUNT(CASE WHEN b.status = 'CONFIRMED' THEN b.booking_id END) AS booked_seats,
    (ac.total_seats - COUNT(CASE WHEN b.status = 'CONFIRMED' THEN b.booking_id END)) AS available_seats,
    ROUND((COUNT(CASE WHEN b.status = 'CONFIRMED' THEN b.booking_id END) * 100.0 / ac.total_seats), 2) AS occupancy_pct,
    COALESCE(SUM(CASE WHEN b.status = 'CONFIRMED' THEN b.total_amount ELSE 0 END), 0) AS flight_revenue
FROM flights f
JOIN airlines al ON f.airline_id = al.airline_id
JOIN aircrafts ac ON f.aircraft_id = ac.aircraft_id
JOIN airports orig ON f.origin_code = orig.airport_code
JOIN airports dest ON f.destination_code = dest.airport_code
LEFT JOIN bookings b ON f.flight_id = b.flight_id
GROUP BY f.flight_id, f.flight_number, al.airline_name, orig.city, dest.city, ac.model, ac.total_seats
ORDER BY booked_seats DESC;

Passengers above the average fare

Confirmed bookings that cost more than the average confirmed ticket.

Nested subquery
View SQL 
SELECT
    p.passenger_id,
    CONCAT(p.first_name, ' ', p.last_name) AS full_name,
    p.email, p.phone, b.pnr, b.total_amount, b.travel_class
FROM passengers p
JOIN bookings b ON p.passenger_id = b.passenger_id
WHERE b.status = 'CONFIRMED'
  AND b.total_amount > (
      SELECT AVG(total_amount)
      FROM bookings
      WHERE status = 'CONFIRMED'
  )
ORDER BY b.total_amount DESC;

Full itinerary (five-table join)

Bookings joined to passengers, flights, airlines and both airport records.

Five-table INNER JOIN
View SQL 
SELECT
    b.pnr,
    CONCAT(p.first_name, ' ', p.last_name) AS passenger_name,
    al.airline_name,
    f.flight_number,
    orig.city AS origin_city,
    dest.city AS dest_city,
    f.departure_time,
    b.seat_number,
    b.travel_class,
    b.total_amount,
    b.status AS booking_status,
    b.booking_date
FROM bookings b
JOIN passengers p ON b.passenger_id = p.passenger_id
JOIN flights f ON b.flight_id = f.flight_id
JOIN airlines al ON f.airline_id = al.airline_id
JOIN airports orig ON f.origin_code = orig.airport_code
JOIN airports dest ON f.destination_code = dest.airport_code
ORDER BY b.booking_id DESC
LIMIT 25;
